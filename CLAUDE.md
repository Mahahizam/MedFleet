# MedFleet

MedFleet is a student portfolio prototype for prioritising maintenance of hospital medical-device fleets, made for biomedical engineering teams. It is not clinically validated and must not be used for real hospital decisions.

The project uses Python and pytest.

Code is in `src/medfleet/` and tests are in `tests/`. Run the tests with `python -m pytest`.
